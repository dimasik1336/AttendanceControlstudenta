# Спринт 3: файлы проекта

Экраны Compose, навигация, ViewModel, проверка ввода. В спринте 3 реализованы список дисциплин, журнал оценок, формы, удаление и валидация. Файлы приведены в итоговой редакции: блоки фильтров, динамики, цели и прогноза добавлялись в спринтах 4–6.

Полная сборка проекта находится в `Sprint_6_Финальная_версия_и_защита/project` (открывать в Android Studio).
